# 健康历史归账号，手环具有独立归属

2026-09-04 用户确认：相同邮箱对应一个健康账号；第一版一个账号同时只绑定一只手环，一只手环只归属一个账号，不支持临时共享，支持明确更换及转让。邮箱等同性必须建立在可信登录验证上，不能用用户自填字符串授权访问健康历史。

蓝牙连接不代表账号拥有权；转让前历史保留原账号，新账号只接收转让后的记录。选择明确归属而非随当前登录账号导入全部手环历史，是为了避免同一设备的历史被重新记到另一个人名下。

## 尚待确定的边界

这些产品方向已确认，尚未实现；已有重复账号的整理、Apple 隐藏邮箱、首次绑定的历史导入、退出与解绑的区别及转让恢复流程仍待设计。不得由本决策推导出自动迁移现有账号数据的授权。

## 硬件前提

当前 SDK 资料未保证 deviceNumber 唯一，蓝牙连接标识也不能充当跨手机的可信实体身份。跨手机独占归属与转让需先验证硬件身份能力；账号切换停止旧同步、未确认归属禁止自动导入历史可独立落实。不能把这两层能力表述为已全部具备。
