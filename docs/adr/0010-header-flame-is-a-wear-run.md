# 焰是连续佩戴的静默事实，琥珀不是续命、佩戴日不是有效夜

2026-09-05 用户确认：首页名字右边加一只焰和一个数字，用来证明连续戴了几天。不要一排灯，不要苹果活动圆环那对火苗加箭头，不要在 header 上印「天」或鼓励语。

佩戴日和有效夜是两件事。有效夜管那一夜的睡眠窗够不够给皮温范围和夜间结论；佩戴日管这个用户日腕上证据够不够——已过五分钟槽里，有心率或明确传感器佩戴的不少于一半（未结束的今天从 04:00 计到现在，已结束的日子 288 槽）。连过蓝牙、床头充电、有 raw 行但没有腕上证据，都不算。Daily Direction 的覆盖率数的是「有没有 raw 行」，会把空 tick 算进去，不能拿来点亮焰。

连续佩戴从今天往回数佩戴日。今天自己一旦够格就计入，不等 04:00。一个已结束、不是佩戴日的用户日把它断开，数字立刻没有；焰变琥珀表示刚断一天，再断一天变灰，灰焰仍占位、永不写 0。琥珀那天再戴上，从 1 开始，不把旧数字救回来——黄不是冻结、不是续命卡。今天还没结束，绝不提前变琥珀。

焰是矢量轮廓，14 × 18pt，不是点阵。第一版画成 8 × 10 网格塞进 16 × 20pt，每格只有 2pt，形状里那几个孤立单格在真机上是脏点，下半身六格实心块把它压成一枚胶囊，而且它比名字的 cap height 高 6pt、比旁边电量点阵高一倍——头部同时挂了两套像素网格。改成贝塞尔是拿「破一套已成立的方格语言」换「18pt 下一眼认得出是火」：两条舌之间那道内凹缺口是唯一让它不是水滴的东西，点阵在这个尺寸下画不出来。已冷用的灰跟电量空壳同一个值，同一个 header 里两枚死掉的标记必须死得一样；`barTrack` 那种 15% 的图表底色在碳底上等于没画。数字不占位：断掉时整段宽度收掉，名字右边不留空白。

整块头像、日期、名字、焰仍是进 Profile 的同一热区。热力图继续只画成分方向，不为佩戴日加第二种涂色，也不新开页面。Hoop 被问到可以当事实引用这个数，不许写成别断签。数字跟训练负荷一样是日结果派生值：服务端结算，App 只读；未结束的今天可以按本地 tick 预览，下一次结算 rebase。它跟健康账号走，不跟某一只手环走。
