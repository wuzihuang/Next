# RESPONSE 二级页也有日 / 周 / 月，周月顶上的数是平均

2026-09-05 用户确认：食物反应点二级页按 Paper `04L` 落地——顶部是分区表盘（04H D · THE DIAL），下面按日 / 周 / 月三档滚动窗口画。日档是半小时包络带；周是七根日柱；月是三十格热力。这重开了 ADR 0008「三档只给睡眠」那一句，但只重开这一张卡。

睡眠的三档不能直接抄过来。睡眠周/月用中位，因为一夜摘表会把均值拖成「糟糕的一周」。RESPONSE 的日档已经是无单位光学点，对照的是本人日间中位；周/月要回答的是「这些天平均落在自己的哪一侧」，两天偏高就应该把顶上的数拉高。所以英雄数是**有记录的日档均值的算术平均**，空日不进平均、也不画成零。对照基线仍是五个有效日之后的日间中位，Near 仍是 ±8%。表盘的尺子切成 Below / Near / Above，游标落在哪一段，哪一段就亮。

窗口与睡眠同一口径：1 / 7 / 30 个用户日，不是自然周月。日档是这个用户日，本地 0 点到现在——ADR 0020 之前它是滚动 24 小时。日档图复用心包络带的规矩——半小时槽的两端是真测到的最低与最高，空槽不画。月档热力格按列往下填再往右，探点仍是水平拖、点的是一列，不在这张卡上发明第二条轴。

当时其余六个 vitals 仍由 `VitalsMetric.timeline` 写死。ADR 0013 之后 HEART 也有三档。步数的一周是累加，心率的一周是日中位的中位，睡眠的一周是七个夜，RESPONSE 的一周是七个日均值——四套聚合不能因为共用三个英文词就合成一套。
