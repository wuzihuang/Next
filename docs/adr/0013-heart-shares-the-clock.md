# 心率二级页是三仪同钟，并且也有日 / 周 / 月

2026-09-05 用户确认：心率二级页按 Paper `04K` 的 Lead 方案落地。顶上是分区表盘（04H D · THE DIAL），下面按日 / 周 / 月三档滚动窗口画包络带。HRV 与夜间血氧不再各开一张二级页，而是同一时钟上的两条伴带。这重开了 ADR 0008「三档只给睡眠」和 ADR 0012「只重开 RESPONSE」那两句。

页还是心率页。英雄数、分区表盘、主包络带都是脉搏。日档半小时一根，尺子仍是固定 40–160 BPM，切点仍是 Tanaka（`hrMax` 180 → 108 · 126 · 144）。周和月是一根柱子一个用户日，空日不插值。周/月顶上的数是**日中位的中位**：一个吵的小时拖不动一周，一个没戴的日子也不进中位、更不画成零。脚注是佩戴天数和窗口最高。

伴带共用这时钟，不共用这把尺。HRV 画窗口里的 RMSSD（0–90），比心率稀。夜间血氧只画夜里自动测到的点（85–100），白天空着——血氧没有白天自动腿。睡眠页仍是夜间 HRV 数字和夜间血氧数字的家；心率页不把它们做成 page-two 卡，也不再印第二个「昨夜 HRV」。

窗口与睡眠、RESPONSE 同一口径：1 / 7 / 30 个用户日，不是自然周月。日档是这个用户日，本地 0 点到现在——ADR 0020 之前它是滚动 24 小时。首页只预加载大约一天的 `raw_samples`，所以进周/月要单独拉 ticks 和 `oxygen_samples`，不能走整份 `load(days:)`。

其余五个 vitals 仍由 `VitalsMetric.timeline` 写死。训练页的三档见 ADR 0015。燃料页见 ADR 0014。
