# 热量页也有日 / 周 / 月，月只讲典型的一天

2026-09-05 用户确认：热量页按 Paper `09H` 落地。同一页 `CALORIES`，顶上是 `SegmentedPills`（DAY / WEEK / MONTH）。这重开了 ADR 0008、ADR 0013 和 `docs/prd/09-fuel.md` 里「燃料页 V1 故意删掉日/周/月」那一句。训练页的三档见 ADR 0015。

三个英文词和睡眠 / HEART / RESPONSE 一样，窗口不是同一套。热量的时钟是用户日（04:00 切日）。日是 1 个用户日，周是滚动 7 个用户日，月是滚动 28 个用户日（四周）。不是自然周月——周一或月初塌成一两根柱子，用户会读成数据丢了。也不是 HEART / RESPONSE 的 30 天：月在这里必须能切成整周，才能把一周说成「一天平均」。

三档说的不是同一句话。DAY 是当天的钟：顶上 09E-C 日曲线（橙阶梯 IN、青斜线 OUT、NOW、BUDGET；实线已发生，虚线按节奏推），下面一份不分餐的食物表（TIME / ITEM / KCAL / P / C / F）。没有 breakfast / lunch / dinner 分组。IN / OUT / GAP 是当天的数。WEEK 的英雄数是七天加总（如 14,870），IN / OUT / GAP 上下三行，下面七天橙/青对柱和七天台账。MONTH 只讲 **A TYPICAL DAY**：英雄数是四周「每天平均」的再平均，量级是 2,xxx，不是 72,370。28 根每日 IN 柱，空柱 = 没吃。四周台账也是一天平均（周合计 ÷ 7）。

数字不能再串成一行。五位数并排会读成 `1487016580-1710`。周/月英雄用上下三行；表内数字用定宽栏 + Jost + nowrap。Doto 只留英雄。热量差额的英文是 `DIFF`、中文是「差额」——`L("GAP")` 仍是热力图空格的「空窗」，两词不要混。日档消耗线按五分钟步数累加，坐着平、走着陡，端点对齐已结算的 `kcal_out`，不是 04:00 到现在的一根尺子。

`LOG A MEAL` 是食物卡上的琥珀状态，点开是一块从底下推上来的 plate（后面收成圆角卡片、缩到 0.88、压一层半透明黑），chrome 和画像页 `SheetFrame` / 加号抽屉同一套。`MARK TODAY AS FASTED` 仍是现有的服务端事务。`MealEntry` 仍是一餐一行（一份 kcal + P/C/F），ITEM 用 `meal.text`。过去日的翻页只活在 DAY，范围仍是最近 7 个用户日。

算术在 `FuelWindowMath`：缺项当 0 才进周加总，全空才是 `——`；月不把 28 天加总。首页只预载约一天，进这页要自己 `load(days: 27)`。
