# 训练页也有日 / 周 / 月，英雄永远是一天的 0–21

2026-09-05 用户确认：训练二级页按 Paper `08C` 方案 A（DIAL）落地。同一页 `TRAINING`，顶上是 `SegmentedPills`（DAY / WEEK / MONTH）。这重开了 ADR 0008、ADR 0013、ADR 0014 和 `docs/prd/08-training.md` 里「训练页 V1 故意删掉日/周/月」那一句。

三个英文词和睡眠 / HEART / RESPONSE 一样。窗口跟 HEART 同粒：用户日（本地 0 点切日，ADR 0020），日是 1 个用户日，周是滚动 7 个用户日，月是滚动 30 个用户日。不是自然周月，也不是热量页的 28 天。自然口径下周一或月初会塌成一两根柱子，用户会读成数据丢了。

三档说的不是同一句话，但英雄数永远停在 0–21 的一天。DAY 是今天的累积：黄环、用户日曲线（`04 · 09 · 13 · NOW · 04`）、原料清单、Z1–Z5 横条、步数与热量、开一场训练。WEEK / MONTH 不再画大环：英雄是大数字（周是已结束天平均，月是典型一天，都不加总），主图是每天一个点的折线。空天是线上的洞，不是 0，也不另标「缺失」。

卡片顺序三档共用：英雄 → 主图 → 原料清单 → 区间图 → 步数与热量图 → CTA。方案 A 的环只留在 DAY。环下仍留边态（stale / over / auto HR off），缺口不再单独标出来。主色是主题黄 lime `#EFF65A`（`NB.lime1`），一级卡和二级页同一套：环、区间弧、目标点分别是 `lime1` / `lime2` / `limePale`。Z4–Z5 与最重一天仍是 ember `#F6A41C`（`NB.ember1`）。训练负荷不走青色。

词汇对齐 `CONTEXT.md` / ADR 0004：叫训练负荷，不叫 strain；卡路里是 estimate（`eActive` / `eOutNow`），厂商耗卡不混用。步数取 `DailyMetrics.steps`，优先读取服务端所有有效槽的 `recorded_steps`，不能把扣除训练时段后的 `allDay` 小计当作全天总步数。Z4+ ≥ 20 分钟的天数只是心率分区摘要，不识别运动类型。

算术在 `TrainingWindowMath`：周/月平均跳过今天和空槽；`UserDay.weekRolls` 从末尾每 7 天往回切，余数落在最老一组，30 天是 2 + 7 + 7 + 7 + 7。首页只预载约一天，进这页要自己 `load(days: 29)`。DEBUG `NB_DEBUG_TRAINING_RANGE=DAY|WEEK|MONTH`。

2026-09-06 算法审查修正：DAY 在英雄下增加估算依据，列出基线夜数、静息心率、有效记录与已过去时长、最近同步，并明确这是规则估算。没有目标仍显示已有活动；历史日没有建议范围时保留未知，不借用今天的范围。有记录天数与佩戴天数分开。心率升高时段不命名为力量训练，移除固定运动建议与向目标外推的预测线。

曲线仅画真实发布点，按实际时间定位，缺口断线、不插值，也不再画阴影或「数据缺失」说明；没有点时保持空态。超过建议范围与达到显示上限分别说明，不再显示“还差 0”。周分区柱使用统一分钟尺度，月视图明确五组覆盖 30 天。分段贡献为按原始负荷分配的分数份额，不等于该时段的非线性分数增量。

2026-09-08 标定修正（#23）：日常和运动不能是同一个上升速率。权重表和分区边界一个字没改，
改的是谁能拿满权重——一个五分钟槽只有落在**一场训练**里才按整权入账。一场训练是：相邻不超过
五分钟的 Z1+ 槽连成一段（中途掉到 Z1 的间歇不切断），这一段里 **Z2 及以上**的时间满十五
分钟。落在训练之外的一律四分之一。

门槛压在 Z2 上是这次改动的要害。F2 §03 那张表自己写着 Z1 是「日常走动」，搬一下午东西是一
整段连续的 Z1；只按「连续十五分钟抬升」判，它就成了训练，一个普通劳作日照样跑到 9.9——第
一版正是这么写的，合成劳作日实测才发现。改成 Z2 门槛后同一天从 14.3 落到 5.2，而同样九个
Z4 槽连成一场是 19.4、打散开是 11.9：数字分得开的是「连不连得起来」，不是「有没有出过力」。

规则算在 `nb.training_load_ticks` 里一次，环、曲线、分段和证据读同一份账；`nb.compute_segments`
的 `ELEVATED HR` 块换成同一个门槛，屏上画成块的那一段就是账上按整权付过钱的那一段。
`docs/prd/F2-numbers.md` §03 的「久坐日 3.9」锚点随之作废。
