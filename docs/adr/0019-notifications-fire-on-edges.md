# 通知按边沿开火，不按钟点；锁屏和前台横幅都出

2026-09-06 用户裁决。手机系统通知（锁屏、解锁横幅、NextBody 在前台）在**通知边沿**上投递：一根阈值被跨过，或一组事实第一次凑齐。废掉 07:00 / 12:30 / 17:00 / 20:30 闹钟，也废掉 F5「只会通知昨夜」和 ADR 0018「推送本期不做」。免打扰仍是闸，不是日程。每个用户日最多 4 条，同一种一天 1 条。计划页的「推送督促」仍在 _Avoid_ 里——当日收束不是计划总结，也不催勾任务。

人选边沿而不是钟，是因为钟点不管数据在不在；人选前台也出横幅，是因为人经常不在锁屏上。人已经在这条深链的目标页上才吞掉，不占预算。
