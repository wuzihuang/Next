## 最终计算性能验收

已通过。真实数据下活动查询将同一静息基线计算了 8,723 次，超过生产 authenticated 的 8 秒 statement timeout。查询内物化 profile/points 并明确夜间索引范围后，调用降至 7 次；相同三天数据隔离回放由 2,461 毫秒降至 542 毫秒，生理计算结果不变。没有提高超时或增加跨请求缓存。

生产真实账户在原 8 秒上限下的回滚验证成功；最终性能迁移已发布。手机自动补传、重算并重载后，训练压力、基础代谢、活动消耗及摄入宏量均出现有效值。当前账号队列为零，本地与云端均为两条餐食。最终手机日志 162 个 HTTP 200、4 个 HTTP 201，无 HTTP 500。

共发布 17 项缺失/修复迁移与 8 个相关 Edge Functions，JWT 校验保持开启。性能补充 10 条 SQL 语义测试通过，并重跑活动、断食及计算版本测试共 64 条断言。源码与验证记录保留在当前工作区。
