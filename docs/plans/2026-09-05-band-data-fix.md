## 真机发现的 SDK 接口差异

SDK SQLite 的 oxygen JSON 保存 RespirationRate，但公开氧气 getter 在当前设备上只返回 Time/OxygenValue。公开原始采样 getter 也会剥离 resRates。两次真机探针分别证实了字段缺失，不能以原始 JSON 单测通过代替 SDK getter 的实际返回契约。

当前设备原始表 resRates 按五分钟槽内顺序展开，与氧气原表在 03:59–13:09 内的 548 条有效呼吸读数逐时间、逐数值一致。最终通过隔离的 `SDKRespirationArchive` 只读访问当前 SDK 的 oxygen_table，使用绑定设备和日期的参数化查询；只向业务层返回时间和呼吸率，不修改厂商库，不读取到其他设备分区。当前厂商库表结构是显式兼容边界，文件、结构或数据异常会报告失败。真机已确认该路径返回 548 条夜间读数。
