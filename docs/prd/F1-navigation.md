# F1 · 导航与信息架构 The Map

## Sec 01 · 四类界面，不许有第五类
读法：从左往右——一条只走一次的直线把人送进来，交给唯一的根；从根出发有五个去处，每一个的返回都回到根；剩下的东西不是页面，是盖在当前这一屏上的东西。设备与测量记录是仅有的两个例外，它们各自真的有一整页内容，所以是全产品仅有的两个二级页（ADR 0010）。

### A · GATE 进来的一条直线
一个账号只走一次。走完之后这三块板的任何一屏都不再可达，除非解绑或换手环。
- BOARD 01 · 4 SCREENS — **登录 Sign in**: Gate → Email → Code → 品牌动画。验证之后一个判定分四支，见 02 节。
- BOARD 02 · 5 SCREENS — **配对 Connect**: 没有返回键、没有「稍后再说」。成功屏底部只有一个按钮，直接交给建档。
- BOARD 03 · 6 SCREENS + 3 SHEETS — **建档与基线 Onboarding**: 两段计数器分开。返回键只在段内有效；扫描一旦开始，返回键消失。BASELINE 整段可跳过。
- ↓ ENTER NEXTBODY · 一次性

### B · THE ROOT 唯一的根
全产品只有这一个根。所有详情页的返回都回到这里，不回上一屏、不回上一次的滚动位置。
- BOARD 04 + 07 · HOME — **首页 390 × 844**
  - 面板 358 × 470：她说话的唯一位置。一次挂一个 widget，widget 可点，落到它所属的详情页。
  - 下屏双卡 358 × 136：整张卡是唯一一热区：训练卡 → 训练详情，燃料卡 → 燃料详情。卡内没有二级按钮。
  - DOCK · 三槽写死：左键切模式、中槽输入、右键要动作。加号单子里的测量走全屏接管，不是新页面。
  - 右上角头像：通往「我的」唯一入口。⚠️ 它现在只是一个头像，没有任何一块板写过它可点。
  - 04D · 计划是根的第三张脸：底栏一条竖线——上箭头、原来那两枚 4pt 点、点下头一行 `PLAN`。竖向上滑打开、下滑关闭。横向仍只锁首屏 ↔ 仪表。不进五个去处、不进 NavigationStack。系统 Home Indicator 仍由 iOS 画。

### C · FROM THE ROOT · 5 从根出发的五个去处
全部是整页，全部不嵌套。每一页记住一个 from (home 或 profile)，返回只认这一层——不做多层历史栈。
- **训练详情 Training** (BOARD 08)：入口两个——训练卡、面板上的 training / session widget。返回 → 首页。
- **燃料详情 Fuel** (BOARD 09)：入口两个——燃料卡、面板上的 fuel / meal widget。返回 → 首页。`LOG A MEAL` 是食物卡上的琥珀状态，点开是盖在本页上的 plate（ADR 0014），不是新页面。
- **Body Battery 详情** (NEW · BOARD 13)：入口一个——面板上的 body battery widget（早晨那一条就是它）。返回 → 首页。它回答「为什么我今天是 72」，形状跟 08 的「为什么是 14.5」同源。
- **成分详情 Composition** (BOARD 10)：入口被修好了——面板上的 recomp / delta / dual widget 现在可点，直接落到这一页。另一个入口是「我的」Composition 卡：格子进当天，卡头进今天。返回 → 来处。
- **我的 Profile** (BOARD 11)：入口一个——右上角头像。返回 → 首页。这一页自己再往下只有两种去处：十四行 sheet，加那两个二级页。热力图下面那块 MEASUREMENTS 列最近三条主动测量，底部 ALL MEASUREMENTS 是这张卡唯一的热区（ADR 0010）。

### D · ON TOP 盖在上面的，不是页面
判断标准：关掉它之后，人应该回到刚才那一屏的同一个滚动位置。
- **全屏接管 Takeover** (06 · 01M · 02M)：测量占满整屏，但它不是新页面——它是首页那块面板长大的样子，所以唯一的出口是关闭标记。品牌动画连关闭标记都没有：那 2.6 秒里用户做不了任何事。
- **底部 sheet · 13 张** (03 · 11 · 12S · 10S)：底下那一屏永远露着标题和至少一行值，高度不超过屏高 78%。下滑关闭 = 放弃本次修改，不弹「要放弃吗」。新增设置项默认走 sheet，要做成页面必须先证明它一屏放不下。
- **设备 Device** (SECOND LEVEL · 1 OF 2)：二级页，因为它真的有一整页内容。从「我的」进，返回回「我的」不回首页。找手环与闹钟是盖在设备页上的 sheet（12Y · FIND LED / ALARMS SWITCH），不是第三级页。自动监测仍是 sheet。
- **测量记录 Measurements** (SECOND LEVEL · 2 OF 2 · ADR 0010)：主动测量的清单，按月分组、月内倒序，会一直长——一屏放不下，这是它能做成页面的理由。从「我的」那块 MEASUREMENTS 进，返回回「我的」不回首页。行点开是盖在本页上的 sheet，不是第三层；sheet 只读，没有删除、编辑、分享，也没有通往成分详情页的路。深链不落到它。
- **THE TEST · 判断一个新东西属于哪一类**：关掉之后人该回到哪？回到同一个滚动位置 → 它是 sheet 或接管。回到首页 → 它是详情页。如果答案是「回到上一个详情页」，那就是设计错了——这个产品里不存在两个详情页之间的路。

## Sec 02 · COLD START 打开 App 的那一刻，人落在哪
判定只看四个事实：有没有有效会话、这个账号绑过手环没有、档案填完了没有、这台手机上有没有存过 deviceId。

| BRANCH | CONDITION | LANDS ON | WHY |
|---|---|---|---|
| NO SESSION | 没有有效会话，或者会话过期（90 天滑动续期走完） | 01 · Gate | 过期不弹「登录已失效」，直接落 Gate。深链一律丢弃，不留待登录后跳转。 |
| NEW | 标识首次出现。账号当场建好，不再单独问一次「注册」 | 品牌动画 → 02 · Connect 01 | 品牌动画只在这一支播，2.6 秒里没有返回、没有按钮。跟首启、配对成功共用同一份实现。 |
| UNPAIRED | 有账号，但这个账号名下没有在册的手环（解绑、换新、或者上次没配完） | 02 · Connect 01（档案保留） | 只补配对这一步。身高体重目标一律不再问，BASELINE 也不再走一遍——档案跟账号走。 |
| PROFILE GAP | 有账号、手环在册，但四个字段没填齐或者目标没选。⚠️ 01 板原来的四支里没有这一支——上次在 ABOUT YOU 中途杀掉 App 的人就掉在这里 | 03 · ABOUT YOU 02（断点续填） | 回到对答案那一屏而不是从 01 屏重来，已填的值原样在。BASELINE 缺席不算 gap——它本来就可跳过。 |
| RETURNING | 有账号、手环在册、档案齐。这一支占日常打开的 99% | 首页（有深链就带深链） | 不插品牌动画一帧。手环连不连得上都不影响落点——连接是后台的事，界面不为它等待。 |
| MERGE | 同一邮箱换了登录方式（Apple → Google → 邮箱）。绑到已有账号，绝不新建第二个 | 按合并后的账号重跑这张表 | 合并本身不是一个落点，它是先合并再判定。这条错了，用户会以为一年的数据丢了。 |

## Sec 03 · DEEP LINKS 从 App 外面进来的四条路
共同规则一条：深链只能落到五个去处之一或首页，永远不能落到 sheet、不能落到全屏接管、也不能落到 gate 链路里的任何一屏。深链的目标不存在时（那一天没有数据、手环已解绑）落首页，不报错。
- `nextbody://home?panel=body_battery` — **早晨那一条**：落到首页，并把 body battery widget 顶到面板上。不落到详情页——用户是被叫醒的，先给他一句话，想看细节自己点。一天只发一条。
- `nextbody://fuel?slot=dinner` — **那句「午饭之后还有吗」**：落到燃料详情并高亮那个 OPEN 餐位。⚠️ 触发条件三个缺一不可：当天未封口、当天有过任意记录、不在进食窗口内。缺一个，断食的人天天被问。
- `nextbody://device` — **手环相关的提醒**：没电、断联太久、有新固件。落到设备页——这是深链唯一允许落到二级页的情况，因为它的返回目标（我的）本来就在栈里。
- `nextbody://composition?date=…` — **判定变了**：10 板要求判定变化必须有可见回执。落到成分详情的那一屏，from=home。⚠️ 这条通知发不发还没定：它可能很有价值，也可能每天都在打扰人，见右列。

## Edge Cases · 05 路由上的五种意外，没有一种该报错
共同规则：任何解析不了、目标不存在、或者时机不对的跳转，一律落首页并静默丢弃，绝不弹「页面不存在」。
1. **DEAD LINK** — from `nextbody://composition?date=2025-11-02` → LANDS ON `HOME · SILENT`。"That day has no data." 目标不存在：那一天没数据、手环已解绑、判定已经变回 NO CALL。落首页，静默。通知是我们发的，目标失效是我们的问题，不该让用户看见一个错误页。
2. **DURING A TAKEOVER** — CURRENT `MEASURING · 00:41 LEFT`，INCOMING LINK `QUEUED · 1 AHEAD`。"Keep your finger where it is." 测量中点了通知：不打断测量。深链排队，测量走完再执行。这跟 07 板「ALERT 也抢不动 measuring」是同一条法律——手指还按在侧键上的那六十秒，比任何一条消息都贵。
3. **BACK FROM SETTINGS** — LEFT FROM `ME → NOTIFICATIONS SHEET · SCROLL 180`，COMES BACK TO `THE SAME SHEET · SCROLL 180`。跳系统设置改权限，回来必须落回那张 sheet 的同一个滚动位置，并且自动重读一次权限态。02 板已经为蓝牙立过这条规矩（回来自动重扫），这里把它升成全局。
4. **KILLED MID-GATE** — KILLED AT `ABOUT YOU 02 / 03 · 3 OF 4 FIELDS FILLED`，REOPENS AT `ABOUT YOU 02 · VALUES INTACT`。在进来那条直线中途杀掉 App：按 02 节的表重判一次，落到 PROFILE GAP 那一支，回到对答案那一屏而不是从头再来。已经过的东西一律不丢。
5. **NO BAND** — TAPPED `PANEL WIDGET · BODY BATTERY`，BAND STATE `DISCONNECTED · 2 HRS`。"The page opens anyway." 路由层不做设备门禁：手环断没断，页面照进，由那一页自己降级成陈旧态。这跟 05 板「dock 不做任何设备门禁」是同一条。在路由层拦住，用户会以为功能坏了；在页面里降级，用户看到的是「数据停在两小时前」。

## 导航 · 硬规则
01. 只有一个根。任何界面的最终返回目标只能是首页。从「我的」进去的详情（成分、身体电量）和两个二级页（设备、测量记录）返回回「我的」。这个产品里不存在两个详情页之间的路。
02. 每个详情页只记一层 from (home 或 profile)，不做历史栈。App 被杀掉之后 from 一律重置为 home——一层的记忆不值得持久化。
03. 面板上的每一个 widget 必须在 envelope 里带 target。没有 target 的 widget 不许上屏，这条校验落在 07 板的 fail-closed 里，跟四个必填字段同级。
04. sheet 不进导航栈，高度不超过屏高 78%，底下那一屏永远露着标题和至少一行值。下滑关闭等价于 Cancel，不弹「要放弃吗」。
05. 全屏接管不进导航栈，唯一出口是关闭标记，且退出前必须先 stop*Test()——不能把测量丢在后台。品牌动画连关闭标记都没有。
06. 深链只能落到五个去处之一、首页、或设备页。解析不了、目标不存在、或者账号还没登录，一律落首页并静默丢弃，绝不弹「页面不存在」。
07. measuring 状态下深链排队，不打断测量，ALERT 也不行。测量结束 (TestState 回 over 或 error) 后执行队列里最新的那一条，中间积压的丢弃。
08. 跳系统设置回来要落回原来那一屏的同一个滚动位置，并自动重读一次权限态。不要求用户回来再点一次「重试」。
09. 路由层不做设备门禁。断连、没电、未配对，一律照常进页，由那一页自己降级。
10. gate 链路走完之后，01/02/03 三块板的任何一屏都不再可达。把人送回去的只有两条路：UNPAIRED 与 PROFILE GAP 两个分支，两者都由冷启动判定给出，不由界面上的按钮给出。

## 上线前必须成立
- 右上角那个头像是「我的」的唯一入口，而没有一块板写过它可点。04 板要补一行：热区不小于 44×44，点击落 Profile。现在它在真屏上看起来只是个装饰。
- 「判定变了」这条通知发不发没定。10 板要求判定变化必须有可见回执，但每天一条很快就变成噪音。建议只在两种时刻推送：从 NO CALL 第一次变成有结论，以及象限翻面。其余情况只在 App 内留回执。
- 通知权限第一次什么时候要，没定。全产品至今没有任何一块板申请过它，而深链这一整节都建在它之上。建议放在 onboarding 结束之后、第一条「昨夜」到达之前，用一个 App 内前置屏说清「我们一天只说一次话」——冷启动就弹系统框，拒绝率会高一倍。见 F5 的权限台账。
- 12 板那两个二级入口 (Alarms、Automatic measurement) 加上「Why won't it connect?」，是设备页下面的第三层。它们一旦做成页面，就成了第三层——二级页只有设备与测量记录两个，没有第三个，更没有第三层。建议全部改成盖在设备页上的 sheet——12S 板已经证明四行 chevron 都能用 sheet 装下。
- 埋点，路由层缺一个这条链就读不出来：`NAV_TO{FROM,TO,VIA}` · `NAV_BACK{FROM,TO}` · `COLD_START{BRANCH,MS}` · `DEEPLINK_OPEN{URL,RESULT}` · `DEEPLINK_DROP{REASON}` · `DEEPLINK_QUEUED{MS}` · `SHEET_OPEN{ROW}` · `TAKEOVER_ENTER{KIND}` · `TAKEOVER_EXIT{KIND,COMPLETED}`
- 验收线三条：冷启动到首页可交互 P50 ≤ 1.2 秒；DEEPLINK_DROP 占 DEEPLINK_OPEN 不到 2%；NAV_BACK 里目标不是 home 或 profile 的比例必须是 0。第三条一旦不为零，说明有人偷偷加了一层栈——那是这块板唯一会被悄悄破坏的地方。
