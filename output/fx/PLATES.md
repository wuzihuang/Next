# 28 块星球板 · 动画逻辑

`render_loops.py` 渲染 28 段无缝 3 秒循环（358×470，24fps，72 帧），LED 点阵风格。本文按板号写清每一块「什么在动、动多少、一圈几次」。参数名与脚本一致，改数值时对着脚本找同名参数即可。

## 全局约定

- **时间**：`t` 从 0 走到 1 是一整圈。所有周期运动都写成 `sin(2π·k·t + 相位)`，`k` 是整数（每圈几次），所以第 72 帧和第 0 帧完全一样，脚本会自检（`seam OK`）。
- **呼吸** `breathe(t, amp, k, ph)` = `1 + amp·sin(2πkt + ph)`。「呼吸 .25」就是亮度在 ±25% 之间起伏，默认每圈一次。
- **虚线爬行**：`dash=(n, duty, t)` 把一条线切成 n 段，偏移量随 t 走一整段，所以一圈刚好推进一格，看起来是连续爬行。偏移写 `-t` 则反向。
- **每板自己的星星** `make_starfield(seed, n)`：n 颗两档亮度的小星（亮档 35%），每颗以 k=1 或 2 独立闪烁；外加 1 颗十字星芒，k=2 脉动。
- **银河层**（本次新加，所有板共用，画在最底下）：`GALAXY[板号] = (倾角, 带中心 y, 强度)`。
  - 240 颗暗星沿一条倾斜的带高斯分布（越靠带心越亮），分成 6 组闪烁：k∈{1,2} × 相位 0°/120°/240°，亮度在 0.2–1.0 之间。星星半径 0.8–1.7px，刻意做到能盖住一个 4px 的 LED 点，否则会被点阵蒙版吃掉。
  - 3 团尘埃云沿带排布，呼吸 .18，并沿带方向来回滑 3px（k=1）。
  - 1 个远处的小星系（椭圆核 + 晕），脉动 .15。
  - 倾角尽量顺着每块板自己的对角线（有斜线/光束的板对齐它），星云板（17、18）和极简板（12、14、27）把强度压到 0.55–0.6，不抢戏。
- **后处理**（每帧固定）：4px 点阵蒙版、暗角、底部安全区压暗、一张固定的胶片颗粒。这些都不随时间变化。

## 23 号 · 月球特写

以前是一颗糊成一团的灰球：陨石坑是随机高斯斑，没有天空，也看不出光从哪来。现在按真实的月球画：

- **构图**：球心 (214, 372)、半径 224，月轮从左边缘升起、顶点在 y≈148，上方留出天空给银河层（倾角 −20°，带心 y=105，强度 1.1）和 6 颗自己的星。右下角被画框裁掉。
- **光照**：光源在左上 (−40, 60)。`terminator=0.82`，夜面压得很黑，明暗界线从右边缘中部斜穿到底边，右下角是夜面。
- **色阶方向**：`sphere_layer` 把朗伯项按 `stops` 映射，0 = 背光、1 = 正对光。其他板的 stops 都是「亮→暗」写的（轮廓光效果），月球是被照亮的实体，所以 23 号的 stops 反过来「暗→亮」写。改坑的明暗时记住这点，否则坑会变成鼓包。
- **表面**：`make_moon_surface(223)` 生成 3 片月海 + 44 个陨石坑（前 6 个大），每个特征存的是**球面经纬度**，不是屏幕坐标。
- **陨石坑画法**（`moon_relief`）：每帧把经纬度旋转后投影到圆盘，按 `pz` 做透视压扁（靠边缘的坑变成扁椭圆并淡出）。一个坑 = 坑底（暗盘，靠光源那侧最暗，是坑沿投的影）+ 内壁（背光侧那半圈受光，细亮弧；向光侧那半圈是暗弧）+ 外坡（向光侧亮、背光侧暗）。月海只有柔和的暗底。
- **动画**：天平动。经度方向 yaw 摆 ±2.4°（k=1），纬度方向 pitch 摆 ±1.1°（k=1，相位 1.0）。所有坑随之一起在球面上缓慢晃动，像真月球被地球引力牵着微微点头。光晕呼吸 .25。
- 陨石坑最小半径 0.035·r ≈ 8px，是为了盖过 4px 的 LED 点阵；更小的坑在点阵下只剩一个点，反而像噪声。

## 重新渲染

```
cd output/fx
.venv/bin/python render_loops.py            # 全部 28 块，约 25 秒（8 进程）
.venv/bin/python render_loops.py 23         # 只渲 23 号
```

输出每块一个 `plate-NN.mp4` 和 `plate-NN.gif`，控制台会打印 `seam OK`；如果出现 `SEAM DIFF`，说明某个周期不是整数圈，循环会跳。
